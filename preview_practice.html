短题 2 · 修复移动语义的 bug

C2 · 第 8 / 11 题

下面的 Wrapper 类独占一个 int* 资源，但移动语义实现有 bug：移动后源对象仍指向同一块内存，析构时二次释放。请修复。

class Wrapper {
    int* p_;
public:
    explicit Wrapper(int v) : p_(new int(v)) {}
    ~Wrapper() { delete p_; }

    Wrapper(Wrapper&& o)
      : p_(o.p_) {}          // bug: 未清空 o.p_
};

要求：移动后源对象可安全析构，不产生 double free；移动构造函数标记 noexcept。

思路：移动语义的本质是「偷」资源——把源对象的指针接过来，并把源对象置为安全状态（nullptr），否则两个对象都会在析构时 delete 同一块内存。

Wrapper(Wrapper&& o) noexcept
    : p_(o.p_) {
    o.p_ = nullptr;   // 关键：源对象置空
}

两个要点：

  • 必须 noexcept——否则 std::vector 扩容时会放弃移动、退化为拷贝。
  • 源对象置空后，其析构是 no-op，天然杜绝 double free。
